## About Me

I'm a Computer Science engineer specializing in Artificial Intelligence, focused on Machine Learning, Data Science, and Generative AI.

I enjoy working across the AI development pipeline — from data preparation and exploratory analysis to model development, experimentation, and building AI-powered applications.

- **Machine Learning:** Model development, evaluation, feature engineering, and optimization.
- **Data Science:** Data preprocessing, exploratory data analysis, visualization, and statistical analysis.
- **Generative AI:** LLM applications, Retrieval-Augmented Generation (RAG), and prompt engineering.
- **AI Engineering:** Building AI services, integrating intelligent models, and developing backend APIs.
- **Software Engineering:** Python development, API design, modular architecture, and maintainable code.

Currently focused on strengthening my Machine Learning engineering skills and building practical AI systems through hands-on projects.
