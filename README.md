## About Me

I'm a Computer Science engineer specializing in Artificial Intelligence, interested in Machine Learning engineering and building AI-powered applications.

My journey in AI started with data analysis and machine learning, and I'm currently expanding my skills toward Generative AI, RAG systems, and AI application development through hands-on projects.

My current focus includes:

- **Machine Learning:** Data preprocessing, feature engineering, model training, and evaluation.
- **Data Analysis:** Exploratory data analysis, visualization, and extracting insights from data.
- **Generative AI:** Exploring LLMs, RAG architectures, and prompt engineering.
- **AI Engineering:** Building AI-powered applications and integrating AI models into software systems.
- **Backend Development:** Developing APIs and AI services using Python.

I believe the best way to learn engineering is by building, experimenting, understanding mistakes, and continuously improving.
